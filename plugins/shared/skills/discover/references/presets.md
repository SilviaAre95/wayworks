# Discover presets

What each lens actually looks for — read the preset you're researching under (or, with `--lens`, whichever named lenses were given instead).

## `code` preset — technical + product

**Technical.** How this has been built before: existing implementations, libraries, protocols. What broke, what stayed brittle, what a shipped system had to work around. *What would break in the first week of running this for real?*

**Product.** Why anyone would want this: the user need, the behavior it replaces, what "good" looks like from outside the code. *Who is worse off if this doesn't ship, and why?*

## `article` preset — prior art + counter-arguments + evidence

**Prior art.** What's already been written that makes this claim. Overlap isn't disqualifying — it's the baseline the article has to add to.

**Counter-arguments.** The strongest case against the thesis, from someone who has actually thought about it, not a straw version.

**Evidence.** What data, cases, or citations would make a skeptical reader believe the claim, and what's missing.

## `talk` preset — prior art + audience

**Prior art.** Same as above: what's already been said, so the talk doesn't repeat a well-known point as new.

**Audience.** Who is in the room, what they already know, and what would change how they act afterward.
